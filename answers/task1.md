# Task 1：从 C 源码到可执行文件

一个 `.c` 文件变成能直接运行的可执行文件，要经过四步：预处理、编译、汇编、链接。

## 1. 预处理

`gcc -E hello.c -o hello.i`

预处理器先处理所有以 `#` 开头的指令。比如把 `#include` 的头文件内容复制进来，把 `#define` 的宏展开，去掉注释。处理完后得到的 `.i` 文件还是 C 代码，但已经“展开”了，文件通常会比原来大很多。

## 2. 编译

`gcc -S hello.i -o hello.s`

编译器把预处理后的 C 代码翻译成汇编代码。这一步会检查语法错误，比如变量未定义、类型不匹配、漏了分号等。如果代码有语法问题，通常就在这里报错。

## 3. 汇编

`gcc -c hello.s -o hello.o`

汇编器把汇编代码变成机器能识别的二进制目标文件 `.o`。`.o` 文件已经包含机器指令，但还不能直接运行，因为它可能还依赖其他文件里的函数或变量。

## 4. 链接

`gcc hello.o -o hello`

链接器把多个 `.o` 文件和系统库合并，解决函数调用时的地址问题。比如 `main.o` 里调用了 `calculator.o` 里的 `add()`，链接器会把它们连起来，生成最终的可执行文件。

## 一句话总结

预处理负责“展开”，编译负责“翻译成汇编”，汇编负责“转成机器码”，链接负责“把碎片拼成完整程序”。
